# GlowSketch

An advanced Python application that transforms standard images into cinematic, glowing neon sketch reveal animations.

---

## 🌟 Key Features

* **Smart Resizing:** Automatically adjusts image aspect ratio to fit the display seamlessly.
* **Multi-Layered Neon Glow:** Combines Canny edge detection with multi-pass Gaussian blurs for bright, realistic neon contours.
* **Dynamic Animations:** Features a randomized mosaic reveal layer, dynamic water reflection, and floating particles.
* **Cinematic Effects:** Smooth camera zoom and pulsing light transitions synchronized for high visual impact.
* **Audio Integration:** Built-in background audio support using `pygame-ce`.

---

## 🛠️ Built With

* **Python**
* **OpenCV** - Computer Vision & Image Processing
* **NumPy** - Array Computations
* **Pygame-CE** - Audio & Sound Management
